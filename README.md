# [PQ] Terra Indomita Chinese Localization

《Imperator: Rome》大型模组 **Terra Indomita** 的简体中文汉化补丁。

This is a Simplified Chinese localization patch for the Imperator: Rome overhaul mod **Terra Indomita**.

## 使用 / Installation

Steam 创意工坊主版：

https://steamcommunity.com/sharedfiles/filedetails/?id=3766505458

备用镜像版：

https://steamcommunity.com/sharedfiles/filedetails/?id=3784985340

建议同时订阅主版和备用镜像版，但在播放集里只启用其中一个。通常启用主版；如果主版因为 Steam 自动审核暂时不可访问，再临时切换到备用镜像版。

You may subscribe to both the main version and the backup mirror, but only enable one of them in your playset. Normally use the main version; switch to the backup mirror only if the main Workshop item is temporarily unavailable due to Steam automated review.

## 仓库内容 / Repository Layout

- `mod/`：实际模组文件，可复制到本地 Imperator: Rome 模组目录。
- `workshop/`：Steam 创意工坊标题、描述和更新说明草稿。
- `docs/loading_tips.md`：新增加载格言、选取标准与出处说明。
- `CHANGELOG.md`：简要更新记录。

## 本地安装 / Manual Installation

将 `mod/` 文件夹复制到：

```text
Documents\Paradox Interactive\Imperator\mod\Terra_Indomita_Chinese_Patch
```

并在同级 `mod` 目录放置启动器 `.mod` 文件。更推荐直接使用 Steam 创意工坊版本。

## 翻译说明 / Translation Notes

本补丁以 Terra Indomita 当前文本为基础，尽量采纳并对照已有社区汉化资源，包括 Imperator Invictus 中文翻译、TEOW（直到世界尽头）相关中文文本，以及玩家实测后反馈的问题修正。

剩余缺口主要由 DeepSeek / GPT 等大模型辅助初译，再进行人工和工具校验，包括格式检查、上下文核验、术语统一和游戏内问题修正。

This patch uses existing community Chinese localizations where suitable, including Imperator Invictus Chinese localization and TEOW-related Chinese text. Remaining gaps were drafted with assistance from large language models such as DeepSeek / GPT, then checked for formatting, context, terminology, and player-reported issues.

## 质量声明 / Quality Notice

这是 AI 辅助汉化与人工校对混合产物，不保证译文完全准确。事件链、任务树、专名、古代制度和区域语境中仍可能存在误译、错配、风格不统一或显示问题。

This is an AI-assisted localization with manual review, not a guaranteed final-quality translation. Event chains, mission trees, proper names, ancient institutions, and regional context may still contain mistranslations, mismatches, inconsistent style, or display issues.
