## 中文描述

这是《Imperator: Rome》大型模组 Terra Indomita 简体中文汉化补丁的备用镜像版。

主版地址：
https://steamcommunity.com/sharedfiles/filedetails/?id=3766505458

本备用版内容原则上与主版保持一致，但不会总是与主版同时更新。它的用途是：当主版工坊物品因为 Steam 自动内容检查而暂时隐藏、无法访问或无法加载时，玩家可以临时切换到本备用镜像版继续游玩。

建议同时订阅主版和备用镜像版，但在播放集里只启用其中一个。平时优先启用主版；如果主版失效、等待审核或无法访问，就在播放集里禁用主版，启用本备用镜像版。等主版恢复后，再切回主版即可。

请不要同时启用主版和备用镜像版。两个模组覆盖的是同一套 Terra Indomita 汉化文件，同时启用通常没有必要，而且未来如果二者版本不同，可能造成加载顺序、文本覆盖或问题定位上的混乱。

本补丁以 Terra Indomita 当前文本为基础，尽量采纳并对照已有社区汉化资源，包括 Imperator Invictus 中文翻译、TEOW（直到世界尽头）相关中文文本，以及玩家实测后反馈的问题修正。剩余缺口主要由 DeepSeek / GPT 等大模型辅助初译，再由人工和 Codex 进行格式检查、上下文核验与术语统一。

需要说明的是，本补丁属于 AI 辅助汉化与人工校对混合产物，不保证译文完全准确。事件链、任务树、专名、古代制度和区域语境中仍然可能存在误译、错配、风格不统一或显示问题。它更适合“先能体验 Terra Indomita 中文内容”，不应视为最终质量的正式译本。如发现问题，欢迎在评论区指出具体国家、事件、任务或截图位置。

## English Description

This is the backup mirror version of the Simplified Chinese localization patch for the Imperator: Rome overhaul mod Terra Indomita.

Main version:
https://steamcommunity.com/sharedfiles/filedetails/?id=3766505458

This backup version is intended to mirror the main patch, but it may not always be updated at exactly the same time. Its purpose is to provide a fallback when the main Workshop item is temporarily hidden, inaccessible, or unavailable because of Steam's automated content review.

You may subscribe to both the main version and this backup mirror, but only enable one of them in your playset. Normally, use the main version. If the main version is unavailable, awaiting review, or cannot be accessed, disable the main version in your playset and enable this backup mirror instead. Once the main version is accessible again, you can switch back to the main version.

Please do not enable the main version and the backup mirror at the same time. Both mods overwrite the same Terra Indomita localization files, so enabling both is unnecessary and may cause confusion with load order, text overrides, or issue reporting if their versions differ.

The patch is based on Terra Indomita's current text and cross-checks existing community translations where possible, including the Imperator Invictus Chinese translation, TEOW-related Chinese localization, and fixes from player reports. Remaining gaps were first drafted with assistance from large language models such as DeepSeek / GPT, then checked by humans and Codex for formatting, context, and terminology consistency.

Please note that this is an AI-assisted localization with manual review, not a guaranteed final-quality translation. Event chains, mission trees, proper names, ancient institutions, and regional context may still contain mistranslations, mismatches, inconsistent style, or display issues. It is intended mainly to make Terra Indomita more playable in Chinese. If you find a problem, reports with the country, event, mission, or screenshot location are very welcome.
