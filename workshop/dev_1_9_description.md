## English Description

```bbcode
[h1]Terra Indomita Dev 1.9 Chinese Localization[/h1]

This is the Simplified Chinese localization patch for the [b]dev 1.9 branch[/b] of the Imperator: Rome overhaul mod [b]Terra Indomita[/b]. It is intended [b]only[/b] for dev builds obtained from Discord or GitHub.

[b][quote]Please note: dev 1.9 is still under active development and its content is not final. This patch was made against a point-in-time dev build, is not guaranteed to stay in sync with the latest dev version, and does not carry the same quality commitment as the stable-release patch.[/quote][/b]

If you play the Steam Workshop public release (1.7.1), [b]please do not subscribe to this item[/b]. Use the stable localization patch instead:

Main version:
[b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3766505458][PQ] Terra Indomita Chinese Localization[/url][/b]

Backup mirror (for when the main version is in Steam's automated review):
[b][url=https://steamcommunity.com/sharedfiles/filedetails/?id=3784985340][PQ] Terra Indomita Chinese Localization - Backup Mirror[/url][/b]

[h1]Coverage[/h1]

This patch currently covers about [b]98%[/b] of dev 1.9 localization keys. The remainder is mostly unfinished upstream placeholder content (TODO entries and variable references), not missing translations.

dev 1.9 continues to change, and newly added or rewritten text may not be localized yet. If you see English remnants, they reflect the patch version and will be addressed in later updates.

[h1]Translation Notes[/h1]

This patch adapts the stable 1.7.1 localization to dev 1.9's new content, drawing on the Imperator Invictus Chinese translation, TEOW Chinese texts, and machine-assisted first drafts, followed by control-token validation, semantic auditing, manual review, and name unification.

[h1]Loading Tips and Screens[/h1]

The loading-tip pool contains [b]312 tips[/b] in total (181 from Terra / Invictus, 72 inherited from TEOW, 59 added by this series).

Four Chinese-themed loading screens are included: [b]Jing Ke's Assassination Attempt[/b], [b]the Grand Ceremony of Qin[/b], [b]the Feast at Hong Gate[/b], and [b]Zhang Qian's Departure from Chang'an[/b], rotating with Terra's and the vanilla screens.

[h1]Known Upstream Issues (Not Caused by This Patch)[/h1]

[list]
[*]The Zhou intro text shows the ruler's name as "Dudley Indomita" — the upstream dev text hardcodes a placeholder character ID.
[*]Some Chinese rulers display a pharaoh crown — the upstream portrait system is unfinished.
[/list]
Both are Terra dev issues present in English as well and will resolve with future upstream updates.

[h1]Quality Notice[/h1]

[quote]
This is an AI-assisted localization with manual review, targeting an unfinished dev version, and is not a guaranteed final-quality translation. Event chains, mission trees, proper names, ancient institutions, and regional context may still contain mistranslations, mismatches, inconsistent style, or display issues.
[/quote]

Reports with the country, event, mission, or screenshot location are very welcome.
```
